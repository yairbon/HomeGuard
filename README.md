# HomeGuard — מערכת אבטחה היברידית מרובת שכבות

פרויקט גמר, קורס חשיפה לחומרה. שותפים: גיא בר, יאיר בונפיל.

## תקציר
מערכת אבטחה לבית המשלבת מחשוב קצה על ESP32 עם עיבוד נתונים מתקדם בפייתון.
מכונת מצבים מרכזית על ה-ESP32 מקבלת קלט ממערך חיישנים (רעידות, דלת מגנטית,
קרן לייזר) לקביעת מצב האזעקה. תקשורת WiFi בין הבקר למחשב (זיהוי פנים) ובין
הבקר לאפליקציה (שליטה מרחוק, התראות).

## מבנה תיקיות
- `esp32/` — קושחת C++ לבקר (state machine, חיישנים, שרת Web)
- `python/` — סקריפט זיהוי פנים + תקשורת עם ה-ESP32
- `app/` — אפליקציית Flutter לשליטה מרחוק והתראות
- `docs/` — מסמכי הפרויקט (כולל טופס ההצעה המקורי)
- `scripts/setup-windows.ps1` — סקריפט התקנה מלא לסביבת הפיתוח (ראה למטה)

**הערה:** התיקייה ממוקמת ב-`C:\dev\HomeGuard` בכוונה (לא תחת `C:\Users\<username>`) —
כלי Android/Gradle נשברים לעיתים כשהנתיב מכיל תווים לא-ASCII (כמו שם משתמש בעברית).

## ארכיטקטורה — אפליקציה
Flutter (native, Android) ← push notifications + סיסמה משותפת אחת ← מדבר עם
בקנד Python מרכזי (FastAPI, טרם נכתב) שמתקשר עם ה-ESP32 ומריץ את זיהוי הפנים.

## סביבת פיתוח
Flutter SDK, Android SDK, ו-JDK 17 מותקנים תחת `C:\dev`. כדי לשחזר את הסביבה
הזו במחשב חדש (Windows), הרץ:
```powershell
.\scripts\setup-windows.ps1
```
הסקריפט מתקין הכל מאפס: JDK 17, Android Studio, Flutter SDK, Android SDK
command-line tools, מקבל את הרישיונות, ומגדיר את משתני הסביבה (JAVA_HOME,
ANDROID_HOME, PATH). בתום ההרצה יש לסגור ולפתוח מחדש את הטרמינל.

בדיקה שהכל תקין: `flutter doctor` (אמור להראות ✓ עבור Flutter וה-Android
toolchain; אזהרת Chrome ניתנת להתעלמות — לא נדרש ל-build של Android).

## חלוקת עבודה
**שותף א' (גיא)** — ניטור היקפי: Tripwire לייזר + IR, חיישן מגנטי לדלת, קוד
מבוסס Interrupts, שרת Web על ה-ESP32 לדאשבורד שליטה.

**שותף ב' (יאיר)** — הגנה פיזית: חיישן רעידות, קודן 4x4, זמזם, ניהול
סיסמאות בזיכרון הבקר, סינון רעשים וסף "כוח מוגזם".

## דרישות
**Must:** זיהוי חדירה (לייזר/דלת) או פריצה בכוח; נטרול דרך קודן פיזי;
אזעקה קולית (Buzzer).

**Nice to have:** אימות ביומטרי (זיהוי פנים) בזמן שהאזעקה דרוכה; דאשבורד
לוג אירועים בזמן אמת; שינוי סיסמה מהאפליקציה.
