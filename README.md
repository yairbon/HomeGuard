# HomeGuard — מערכת אבטחה היברידית מרובת שכבות

פרויקט גמר, קורס חשיפה לחומרה. שותפים: גיא בר, יאיר בונפיל.

## תקציר
מערכת אבטחה לבית המשלבת מחשוב קצה על ESP32 עם עיבוד נתונים בפייתון.
**שלושה בקרי ESP32 נפרדים** — לוח לכל חיישן, לא בקר מרכזי אחד כמו שתוכנן
במקור: אולטרה-סוני, רעידות, ודלת+קודן. לוח הדלת/קודן הוא היחיד שמריץ מכונת
מצבים ומחזיק סמכות לדריכה/נטרול (יש לו את הקודן); שני האחרים "טיפשים"
בכוונה — הם רק מדווחים, והבקנד מחליט אם הדיווח משנה.

בקנד FastAPI מרכזי מאחד את השלושה, מריץ את זיהוי הפנים, ומשרת את
האפליקציה ב-REST + WebSocket.

> **הערה על שמות:** ה"לייזר" מהמסמך המקורי מומש בפועל כחיישן אולטרה-סוני
> (HC-SR04). השם עודכן בכל המערכת (`ultrasonic`, לא `laser`) כדי לשקף את
> החומרה האמיתית.

## מבנה תיקיות
- `esp32/` — שלוש קושחות C++ נפרדות, אחת לכל לוח (ראה `esp32/README.md`)
- `python/` — בקנד FastAPI: זיהוי פנים + תקשורת ESP32 + API לאפליקציה
  (ראה `python/README.md`)
- `app/` — אפליקציית Flutter לשליטה מרחוק והתראות
- `docs/` — מסמכי הפרויקט (כולל טופס ההצעה המקורי)
- `scripts/setup-windows.ps1` / `scripts/setup-wsl.sh` — התקנת סביבת
  הפיתוח (ראה למטה)
- `scripts/setup-claude-plugins.{sh,ps1}` — התקנת סט ה-plugins של
  Claude Code שהפרויקט עובד איתו (ראה `CLAUDE.md`)

**הערה:** התיקייה ממוקמת ב-`C:\dev\HomeGuard` בכוונה (לא תחת `C:\Users\<username>`) —
כלי Android/Gradle נשברים לעיתים כשהנתיב מכיל תווים לא-ASCII (כמו שם משתמש בעברית).

## ארכיטקטורה — אפליקציה
Flutter (native, Android) ← התראות מקומיות + סיסמה משותפת אחת ← מדבר עם
בקנד FastAPI (`python/`) שמתקשר עם שלושת לוחות ה-ESP32 ומריץ את זיהוי
הפנים. הקישור חי: REST לפעולות שהאפליקציה יוזמת, ו-WebSocket (`/ws`)
לכל שינוי מצב שהיא רק צריכה לדעת עליו — כולל שינויים שמקורם בלוחות עצמם
או במכשיר אחר. כתובת הבקנד ניתנת לעריכה במסך Settings (נדרש restart).

ההתראות הן `flutter_local_notifications` — **לא push אמיתי**: הן עובדות
כשהאפליקציה חיה (foreground/background), לא כשהיא סגורה לגמרי. Push אמיתי
דורש פרויקט Firebase ו-`google-services.json` (ראה `CLAUDE.md`).

## הרצה מהירה
```powershell
# בקנד
cd python
.\venv\Scripts\python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
# בדיקה שהכל עובד end-to-end (~דקה, כולל המתנה אמיתית ל-lockout)
.\venv\Scripts\python.exe simulate.py
```
האפליקציה נבנית דרך WSL2 בגלל תקלת Winsock ידועה במכונת הפיתוח — ראה
`CLAUDE.md`, או פשוט `/flutter-build`.

## סביבת פיתוח
Flutter SDK, Android SDK, ו-JDK 17 מותקנים תחת `C:\dev`. כדי לשחזר את הסביבה
הזו במחשב חדש (Windows), הרץ:
```powershell
.\scripts\setup-windows.ps1
```
הסקריפט מתקין הכל מאפס: JDK 17, Android Studio, Flutter SDK, Android SDK
command-line tools, מקבל את הרישיונות, ומגדיר את משתני הסביבה (JAVA_HOME,
ANDROID_HOME, PATH). בתום ההרצה יש לסגור ולפתוח מחדש את הטרמינל.

בדיקה שהכל תקין: `flutter doctor` (אמור להראות ✓ עבור Flutter וה-Android
toolchain; אזהרת Chrome ניתנת להתעלמות — לא נדרש ל-build של Android).

**אם ה-build הנייטיבי קורס** עם `Unable to establish loopback connection` —
זו תקלת Winsock ברמת המערכת, לא בעיה בפרויקט. הפתרון שעובד הוא בנייה דרך
WSL2: `wsl -d Ubuntu -- bash /mnt/c/dev/HomeGuard/scripts/setup-wsl.sh`.
הרקע המלא ב-`CLAUDE.md`.

## חלוקת עבודה
**שותף א' (גיא)** — ניטור היקפי: חיישן מרחק (מומש כאולטרה-סוני HC-SR04
במקום ה-Tripwire לייזר שתוכנן), חיישן מגנטי לדלת, שרת Web על לוח
הדלת/קודן לשליטה מרחוק.

**שותף ב' (יאיר)** — הגנה פיזית: חיישן רעידות, קודן 4x4, זמזם, ניהול
סיסמאות, סינון רעשים וסף "כוח מוגזם".

## דרישות
**Must:** זיהוי חדירה (אולטרה-סוני/דלת) או פריצה בכוח; נטרול דרך קודן
פיזי; אזעקה קולית (Buzzer). — **הושלם.**

**Nice to have:** אימות ביומטרי (זיהוי פנים) בזמן שהאזעקה דרוכה — מומש
(OpenCV, Haar cascade + LBPH); דאשבורד לוג אירועים בזמן אמת — מומש (מסך
event log + WebSocket); שינוי סיסמה מהאפליקציה — מומש.

## מה עוד חסר
- הקודן הפיזי 4x4 עדיין מדומה דרך ה-Serial Monitor (בכוונה — לבדיקת
  מכונת המצבים לפני החיווט). ראה `esp32/README.md`.
- פרטי ה-WiFi ו-`backendHost` בשלוש הקושחות הם placeholders — למלא לפני
  הבהוב.
- הקושחות נבדקו שהן מתקמפלות בלבד; לא נבדקו על לוחות אמיתיים.
- אימות: סיסמה משותפת אחת + נעילה של 30 שניות. מספיק לפרויקט קורס, לא
  מספיק כדי לחשוף את הבקנד לאינטרנט הפתוח — לכן Tailscale ולא port
  forwarding (ראה `CLAUDE.md`).
