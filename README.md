# HomeGuard — מערכת אבטחה היברידית מרובת שכבות

פרויקט גמר, קורס חשיפה לחומרה. שותפים: גיא בר, יאיר בונפיל.

## תקציר
מערכת אבטחה לבית המשלבת מחשוב קצה על ESP32 עם עיבוד נתונים בפייתון.
**שלושה בקרי ESP32 נפרדים** (לוח לכל חיישן) מדווחים לבקנד FastAPI מרכזי,
שמאחד את התקשורת, מריץ זיהוי פנים, ומשרת אפליקציית Flutter לשליטה מרחוק
ולהתראות.

## מבנה תיקיות
- `esp32/` — קושחת C++ לשלושת הלוחות (ראה `esp32/README.md`)
- `python/` — בקנד FastAPI + זיהוי פנים (ראה `python/README.md`)
- `app/` — אפליקציית Flutter (Android) לשליטה מרחוק והתראות
- `docs/` — מסמכי הפרויקט (כולל טופס ההצעה המקורי)
- `scripts/` — סקריפטי התקנה לסביבת הפיתוח (ראה למטה)

**הערה:** התיקייה ממוקמת ב-`C:\dev\HomeGuard` בכוונה (לא תחת `C:\Users\<username>`) —
כלי Android/Gradle נשברים לעיתים כשהנתיב מכיל תווים לא-ASCII (כמו שם משתמש בעברית).

## ארכיטקטורה

```
  ┌───────────────────┐   ┌──────────────────┐   ┌────────────────────────┐
  │ ultrasonic_sensor │   │ vibration_sensor │   │ door_keypad_controller │
  │    (HC-SR04)      │   │     (SW420)      │   │  קודן + חיישן דלת      │
  └─────────┬─────────┘   └────────┬─────────┘   └───────────┬────────────┘
            │  POST /esp32/*       │                         │  ▲
            │  + X-Device-Key      │                         │  │ POST /arm /disarm
            └──────────────┬───────┴─────────────────────────┘  │ + X-Device-Key
                           ▼                                     │
                 ┌──────────────────────┐──────────────────────-─┘
                 │  בקנד FastAPI        │
                 │  (python/)           │  ← זיהוי פנים (YuNet + SFace)
                 └──────────┬───────────┘
                            │  REST + WebSocket /ws
                            │  + Authorization: Bearer <token>
                            ▼
                 ┌──────────────────────┐
                 │  אפליקציית Flutter   │
                 │  (app/, Android)     │
                 └──────────────────────┘
```

שני הלוחות הראשונים "טיפשים" בכוונה — הם לא יודעים אם המערכת דרוכה, פשוט
מדווחים, והבקנד מחליט אם זה משנה. לוח הקודן הוא הסמכות לדריכה/נטרול (יש לו
את הקודן הפיזי), ולכן הוא היחיד שגם מקבל פקודות ולא רק שולח.

## אבטחה

זו מערכת אזעקה, ולכן שום endpoint לא פתוח:

- **האפליקציה** מתחברת עם סיסמה ומקבלת session token (תקף 12 שעות), שנשלח
  ככותרת `Authorization: Bearer` בכל בקשה. הסיסמה נשמרת כ-hash (scrypt עם
  salt), לא בטקסט גלוי. שינוי סיסמה מבטל את כל הסשנים האחרים.
- **הלוחות** מזדהים עם מפתח משותף (`X-Device-Key`) שמוגדר ב-`esp32/secrets.h`.
  בלעדיו אי אפשר לזייף דיווח פריצה — או לזייף דיווח "המערכת נוטרלה".
- **נעילה** אחרי 3 ניסיונות שגויים, על `/login` וגם על `/change-password`.
- `/health` הוא ה-endpoint הציבורי היחיד.

**סודות לא נכנסים לגיט:** העתק את `esp32/secrets.h.example` לכל אחת משלוש
תיקיות הסקיצות בשם `secrets.h` ומלא את הערכים (פרטי WiFi, כתובת הבקנד,
מפתח המכשיר, קוד הקודן).

## הרצה

בקנד:
```powershell
cd python
python -m venv venv
.\venv\Scripts\pip.exe install -r requirements.txt
.\venv\Scripts\python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
בהרצה ראשונה הוא ייצר מפתח מכשיר וידפיס אותו ללוג — זה מה שצריך להיכנס
ל-`secrets.h`. פירוט מלא: `python/README.md`.

אפליקציה: `/flutter-build` (custom command) או ידנית דרך WSL2 — ראה
`CLAUDE.md`. את כתובת הבקנד עורכים במסך Settings באפליקציה.

## סביבת פיתוח
Flutter SDK, Android SDK ו-JDK 17 מותקנים תחת `C:\dev`. לשחזור במחשב חדש:
`.\scripts\setup-windows.ps1`. אם הבנייה נשברת עם
`Unable to establish loopback connection` — זו תקלת Winsock ברמת המערכת;
הפתרון שעובד הוא בנייה דרך WSL2 (`scripts/setup-wsl.sh`). ראה `CLAUDE.md`.

## חלוקת עבודה
**שותף א' (גיא)** — ניטור היקפי: חיישן אולטרה-סוני, חיישן מגנטי לדלת,
שרת Web על ה-ESP32 לשליטה מרחוק.

**שותף ב' (יאיר)** — הגנה פיזית: חיישן רעידות, קודן 4x4, זמזם, ניהול
סיסמאות, סינון רעשים וסף "כוח מוגזם".

## דרישות
**Must:** זיהוי חדירה (אולטרה-סוני/דלת) או פריצה בכוח; נטרול דרך קודן פיזי;
אזעקה קולית (Buzzer). — **הושלם.**

**Nice to have:** אימות ביומטרי (זיהוי פנים) — הושלם; דאשבורד לוג אירועים
בזמן אמת — הושלם; שינוי סיסמה מהאפליקציה — הושלם.

**לא ממומש (מתועד ככזה):** חיוג אוטומטי למספר חירום (ההגדרה נשמרת, החיוג
עצמו לא נכתב); auto-arm לפי night mode (הדגל נשמר, אין תזמון).
